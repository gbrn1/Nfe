# Cálculo de Impostos para NFe

Script simples em Python para calcular valores de **ICMS, PIS e COFINS** a partir do valor total de uma nota fiscal.

## Como usar

Execute o script:

```bash
python nfe.py
```

Informe o valor total da nota fiscal quando solicitado.

### Exemplo

```text
Valor total: 10000

ICMS  307,00  PIS 30,00  COFINS 125,30
```

## Tecnologias

* Python 3
* `input()`
* `float`
* Formatação de strings

> Projeto simples desenvolvido para praticar Python e automatizar um cálculo utilizado no dia a dia.
